# 플레이 방법 
## 입력
### 1P 입력
이동 : WASD
공격 : SpaceBar
### 2P 입력
이동 : 방향키
공격 : 오른쪽 Shift

## 기술표
※1P기준
### 앞 대쉬 : 빠르게 앞 입력 두 번 입력
앞으로 빠르게 전진합니다. 잔깜동안 무적시간이 있고, 상대방의 뒤로 이동이 가능합니다.
### 백 대쉬 : 빠르게 뒤 입력 두 번 입력
뒤로 빠르게 후퇴합니다. 앞 대쉬처럼 무적시간이 있지 않습니다. 
### 하단 공격 : 공격 버튼
5프레임 발동 공격입니다. 무릎 공격보다 느리지만 무릎 공격보다 공격 거리가 깁니다. 공격력은 0입니다.
### 무릎 공격 : 앞 혹은 뒤 입력과 동시에 공격 버튼
3프레임 발동 공격입니다. 빠르게 발동 되지만 하단 공격보다 공격 거리가 짧습니다. 공격력은 0입니다.
### 전진 기술 : ↓↙← + 공격 버튼
전진성이 있는 기술입니다. 후 딜레이가 조금 긴 공격입니다. 공격력은 1입니다.
### 무적기 기술: →↓↘ + 공격 버튼
6프레임간의 무적기가 있는 기술입니다. 후 딜레이가 긴 공격입니다. 공격력은 1입니다.
#### 하단 공격, 무릎 공격에서 전진 기술과 무적기로 캔슬할 수 있습니다.

## 게임 승리 방법
파이터들의 체력은 모두 동일하게 1입니다. 먼제 체력을 0으로 만드는 쪽이 승리합니다.
공격력이 1 이상인 공격을 적중시켜야만 체력을 깎을 수 있습니다.
가드를 하거나 공격에 적중당했을 경우 가드브레이크 게이지가 하나씩 줄어 듭니다.
가드브레이크 게이지가 모두 줄어들었을 경우 공격을 가드했을 시 가드 브레이크가 발생합니다. 
가드 브레이크가 발생하게 될 경우 가드 브레이크의 모션이 길기 때문에 그 안에 공격을 당할 가능성이 커집니다. 
위 방법으로 3라운드를 먼저 선취하는 쪽이 승리합니다.
